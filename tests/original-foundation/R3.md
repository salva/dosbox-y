# R3 machine-save host-file policy

Machine archives preserve DOS handle metadata and cursors, not host file content.
`SaveState::save/load` no longer call `flagged_backup/flagged_restore`. The
FLAGSAVE registry, sidecar utility implementations and interfaces remain intact;
no transactional sidecar scheme was added. Existing host modifications survive
same-process and fresh-process restore. Native open/seek failures remain fatal
after installation starts, not successful rollback.

LocalFile handles superseded by restored slots are explicitly retired without
DOS timestamp callbacks or applying old metadata. fclose failure consumes the
handle and fails the session. Other file/device families keep existing behavior.

## Reproduce

Build exported commit 3862cdf726ed5a12db09cbacc7cd751c320305c3 (tree
72088ea29e9961feabc524d895a49933c9d197a6): `bash autogen.sh`; out-of-tree
configure `--enable-debug=heavy --enable-dosbox_agent --enable-sdl2
--disable-opengl --disable-avcodec` with either `--enable-debug-lua` or
`--disable-debug-lua`; `make -j6` (no-Lua used -j4).
Subsequent commits change only fixtures. Production/build input equality was
checked for all 1531 tracked src/include/configure.ac/Makefile.am inputs.

Set DOSBOX_TEST_BINARY to the configured binary and run:

- `DOSBOX_TEST_FILE_STATE=1 python3 tests/original-foundation/stopped-save.py`
  in both builds. NASM fixture opens FLAG.TXT read-only, seeks to 3, and holds
  at 0814:0180. Host bytes are changed before restore. Explicit Run after
  restore reads `nged`, reports count4/cursor7, write-error5, enumerates exactly
  ONE.DAT/TWO.DAT and reports exhausted search error18. Same/fresh restore,
  held owner equality and corrupt-owner fatal-disposal checks remain.
- `DOSBOX_TEST_FLAGGED=1 python3 tests/original-foundation/stopped-save.py`
  retains original stopped/no-advance/explicit single-step assertions.
- `python3 tests/machine-service/lua-production-runtime.py` on Lua build.
- `python3 tests/stopped-continuation/exclusive-runtime.py` on Lua build;
  no-Lua also calls `run(False,no_lua=True); run(True)` via runpy.

Environment: Linux, SDL2 surface, normal CPU/fixed3000, nosound, dummy audio,
private harness-owned Xvfb. Not universal hardware/guest/config parity.
Directory witness starts a **new** current-host search after restore. An active
native search's persistence is not implemented or qualified here; it remains
parent resource-owner reconstruction work. No forced close-error injection or
all file/device-owner reconstruction claim. Parent R2/R4 and broader parity,
frontends and composed acceptance remain separate.
